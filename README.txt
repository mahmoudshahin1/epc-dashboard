========================================================
  EPC Production Dashboard — دليل الاستخدام
========================================================

■■ شكل المشروع (كل حاجة في مكانها) ■■
========================================================
  index.html              → هيكل الصفحة فقط (HTML نضيف)
  css/style.css           → كل التنسيقات (الألوان والشكل)
  js/app.js               → كل منطق الداشبورد (حسابات/رسوم/فلاتر)
  js/data.js              ← بتتولد تلقائياً (البيانات + الخطة + البصمة)
  js/vendor/xlsx.full.min.js → مكتبة قراءة الإكسيل (SheetJS)
  assets/logo.png         → لوجو الشركة
  tools/update_dashboard.py → سكربت البناء (يقرا الـ ERP ويبني dist)
  update_dashboard.bat    → بناء بدبل كليك
  publish.bat             → بناء + نشر على Netlify
  plan.json               → خطة الشهر (للسكريبت)
  dist/                   ← ناتج البناء:
      index.html + css/ + js/ + assets/   → الموقع (لـ Netlify)
      standalone.html                     → ملف واحد (واتساب/أوفلاين)

■■ الطريقة الأسهل (من غير أي تنصيب) ■■
========================================================
1. افتح  dist/standalone.html  في أي متصفح.
2. صدّر ملف الإنتاج من الـ ERP (0040_qa.xls).
3. اسحب الملف وافلته جوه الصفحة — أو دوس 📂 استيراد ملف ERP.
4. خلاص — كل الأرقام اتحدثت فوراً، والصفحة بتفتكر آخر استيراد.

• زرار 🎯 الخطة: سجل خطة الشهر (إجمالي/AL/CU) — بتتحفظ
  في المتصفح ولكل شهر خطته لوحده.
• قائمة الشهور فوق: أرشفة وتنقل بين الشهور + 🆕 شهر جديد
  + ⬇️ نسخة احتياطية / ⬆️ استرجاع (كل ده مشروح جوّه الصفحة نفسها).
• الداشبورد يشتغل من غير نت — standalone.html ملف واحد
  يتبعت واتساب/إيميل ويتفتح على الموبايل والكمبيوتر.

■■ البناء من ملف الـ ERP (سكريبت) ■■
========================================================
التثبيت (مرة واحدة):
1. Python من https://www.python.org/downloads/
   ⚠️ صحّن على "Add Python to PATH".
2. في Command Prompt:   pip install openpyxl xlrd

التشغيل:
• دبل كليك  update_dashboard.bat
  (بيدوّر على 0040_qa.xls في فولدر المشروع أو الديسكتوب)
• أو حدد الملف:  python tools\update_dashboard.py "D:\Reports\today.xls"
• الناتج: فولدر dist/ محدّث (الموقع + standalone.html)

تحديث تلقائي بميعاد (Task Scheduler):
   schtasks /create /tn "EPC Daily Dashboard" /tr "pythonw \"C:\EPC\tools\update_dashboard.py\" \"C:\EPC\0040_qa.xls\"" /sc daily /st 07:30
• للتجربة:  schtasks /run /tn "EPC Daily Dashboard"
• للإلغاء:  schtasks /delete /tn "EPC Daily Dashboard" /f

■■ النشر على لينك ثابت (Netlify) ■■
========================================================
الدليل الكامل في  README-NETLIFY.txt — ملخصه:
حساب مجاني → اسحب فولدر dist على Netlify Drop → خد لينك →
بعدها يومياً دبل كليك publish.bat يتنشر التحديث لكل الناس.
الزوار قراءة فقط، والنشر من حسابك بس (فعّل 2FA).

■■ خطة الشهر (plan.json) ■■
========================================================
   "plan_total_tons": 4442,   ← إجمالي خطة الشهر بالطن
   "plan_AL_tons": 3139,      ← خطة الألومنيوم (صفر = إلغاء)
   "plan_CU_tons": 1303,      ← خطة النحاس
   "for_month": "2026-11",    ← اختياري: تحذير لو الشهر مش مطابق
(أو سجلها من زرار 🎯 الخطة جوّه الداشبورد — أسهل)

■■ مشاكل شائعة ■■
========================================================
• "مكتبة قراءة الإكسيل مش مدمجة" في standalone → معناها إن
  النسخة اتبنَت من غير js/vendor — اعمل بناء تاني بالسكريبت.
• رسالة إن xlrd مش موجود والملف .xls → pip install xlrd
• السكريبت مش لاقي الملف → حطه في فولدر المشروع أو مرر المسار.
• عدّلت في الشكل؟ عدّل css/style.css · المنطق؟ js/app.js
  الهيكل؟ index.html — وبعدين بناء تاني عشان dist تتحدث.
